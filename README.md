# 《动手学深度学习》学习笔记 📘

**作者：王令基**

## 项目简介

这是我学习李沐老师《动手学深度学习》课程时整理的个人笔记。

本仓库以《动手学深度学习》教材和李沐老师的配套课程为主线，记录课程中的核心概念、数学原理、PyTorch 代码实现以及个人理解。

笔记主要使用 Jupyter Notebook（`.ipynb`）编写，并在 Google Colab 和本地 PyTorch 环境中运行。

## 📚 学习内容

本仓库的内容按照《动手学深度学习》的章节顺序整理，主要包括：

- 课程核心概念
- 数学公式与简单推导
- 教材代码的运行与分析
- PyTorch 代码注释
- 张量形状与数据流说明
- 模型训练过程分析
- 常见错误与调试记录
- 个人理解与学习总结
- 部分课后练习

## 💻 学习方式

学习每一节课程时，我通常会按照以下过程进行：

1. 阅读对应教材内容；
2. 观看李沐老师的课程视频；
3. 手动运行教材中的代码；
4. 分析代码的执行过程和张量形状；
5. 修改部分参数并观察结果；
6. 整理概念、代码注释和个人理解。

本仓库不仅保存最终代码，也会保留部分学习、修改和调试过程。

通过持续学习这门课程，希望能够：

- 掌握 PyTorch 的基本使用方法；
- 理解深度学习模型的基本原理；
- 熟悉数据处理、模型构建、训练和评估流程；
- 提高阅读与调试深度学习代码的能力；
- 为后续学习更深入的深度学习内容打下基础。
